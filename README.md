# Rain Keys · 빗방울 건반

기기에서 나오는 소리(유튜브, 멜론 등)를 실시간으로 분석해 **음 높이 = 가로 위치, 박자 = 착수 타이밍**으로 밤바다에 빗방울을 떨어뜨리는 웹앱입니다. 소리를 재생하지 않고 분석만 합니다.

- 화면 위의 88건반(A0~C8)이 실제 피아노와 같은 배치로 놓여 있고, 소리가 들린 건반이 켜지며 그 건반 바로 아래로 비가 떨어집니다. 피아노 연주 영상에서 노트가 내려오는 자리와 같은 느낌이에요.
- 낮은 음은 왼쪽(크고 무거운 방울), 높은 음은 오른쪽(작고 가벼운 방울)
- 모든 비는 소리에서 나옵니다(난수 비 없음). 음이 시작되는 순간 그 건반 자리에 큰 방울, 음이 이어지는 동안 그 건반 자리에 잔비가 내리고, 소리가 클수록 비가 굵어집니다. 조용해지면 비가 그칩니다.
- 실사 느낌: 바람·돌풍·난류 속에서 3D로 떨어지는 빗방울(원근에 따라 기울어지는 빗줄기), 실제 속도·크기의 스플래시, 수면의 빗방울 파문, 비구름 낀 밤하늘, 피사계 심도 흐림·불빛 번짐·필름 그레인
- 스플래시: 분화구 → 얇은 물막 크라운(림의 리가먼트와 구슬, 이중·비대칭) → 워딩턴 제트와 핀치오프 → 2차 착수(미니 크라운, 떠 있는 방울) → 모세관 파문 열차. 모든 요소가 수면에 비칩니다.
- 입력: 💻 기기 소리(PC Chrome·Edge의 화면/탭 공유 + 오디오 공유) 또는 🎤 마이크(모바일)

## 조작
평소엔 오른쪽 아래 아이콘 3개(🔊 입력 · ⛶ 전체화면 · ⚙ 설정)만 보이고, 3초간 조작이 없으면 이것도 사라져 바다만 남습니다.

| 항목 | 뜻 |
|---|---|
| 장면 | **잔잔한 비**(기본, 방울마다 매끈한 고리 1~2개) · **물결 가득**(촘촘한 파문이 오래 퍼짐). 예전 `/v1/` 주소는 물결 가득으로 열려요 |
| 곡 분위기 | 조용한 곡 / 보통 / 시끄러운 곡. '직접 조절'을 펼치면 미터의 점선(넘은 음 = 빗방울)을 끌어 맞출 수 있어요 |
| 듣는 기기 | 스피커 / 유선 이어폰 / 블루투스 / TV·모니터. 방울이 물에 닿는 순간을 귀에 들리는 소리에 맞춰요. '직접 조절'로 미세 조정 |
| 건반 표시 · 저사양 | 저사양은 해상도와 입자 수를 줄입니다. 휴대폰은 자동으로 켜지고, 3초 이상 40fps 미만이면 자동 전환 |
| 단축키 | H 화면만 보기 · F 전체화면 · S 설정 · Esc 닫기 |

설정은 이 브라우저에 저장됩니다. 휴대폰에서는 설정이 아래에서 올라오는 시트로 열려요. 주소에 `?scene=lively`처럼 장면을 지정할 수도 있어요.

장면은 `index.html`의 `SCENES` 목록 한 항목(내리는 것·하늘·바람·물 표현 값 묶음)이고, 설정 카드의 장면 타일도 이 목록에서 만들어져요. 눈·강한 바람·다른 배경은 항목을 더하고 그 값을 읽는 부분만 구현하면 됩니다.

## Windows 데스크톱 앱 · 화면보호기 (`desktop/`)
웹과 같은 `index.html`을 Electron으로 띄웁니다. 앱에서는 **공유 창이나 마이크 권한 없이** 기기의 모든 소리(WASAPI 루프백)를 바로 듣습니다.

- 앱을 열고 아래 패널의 **🌧 화면보호기로 설정**을 누르면 Rain Keys가 현재 사용자의 화면보호기로 등록되고, Windows 화면보호기 설정 창이 열려 대기 시간을 고를 수 있어요.
- 화면보호기 중에는 주 모니터에 바다, 다른 모니터는 검은 화면입니다. 마우스를 움직이거나 키·클릭을 하면 끝나요.
- `RainKeys.scr`은 Windows가 부르는 작은 런처(Go)로, 설치된 `RainKeys.exe`를 `--saver`로 실행합니다. 설정 창의 작은 미리보기는 아직 비어 있어요.
- 영상이 재생 중이면(유튜브 등) Windows가 화면보호기 시작을 막을 수 있어요.

개발(필요: Node, Go):
```
cd desktop
npm install
npm start          # 앱
npm run saver      # 화면보호기 모드로 바로 실행
npm run dist       # .scr 빌드 + 설치 파일 dist/RainKeys-Setup-<버전>.exe
```

## GitHub Pages 배포
1. GitHub에서 새 저장소를 만듭니다(예: `rain-keys`, Public).
2. 이 폴더의 `index.html`, `README.md`, `.nojekyll`을 업로드합니다(웹에서 **Add file → Upload files**).
3. **Settings → Pages → Build and deployment → Source: Deploy from a branch**, Branch는 `main`, 폴더는 `/ (root)`로 두고 저장합니다.
4. 1~2분 뒤 `https://<아이디>.github.io/rain-keys/`에서 열립니다.

화면/마이크 공유는 https(또는 localhost)에서만 동작하므로 GitHub Pages 주소로 여세요.

## 기술 메모
- WebGL2: 하늘·바다를 프레임버퍼에 그리고, 그 위에 크라운·제트·분화구를 실제 3D 삼각형으로, 물방울·기포를 구 임포스터로 그립니다(프레넬 반사, 배경 굴절, 볼록렌즈의 뒤집힌 상, 가장자리 굴절 링, 기포의 간섭색).
- 파문: 셰이더 안에서 사건별로 파장이 다른 성분이 서로 다른 속도로 퍼지는 해석해를 계산합니다(격자 없음, 최대 64개 동시).
- 음 분석: 88건반 전체(A0~C8). FFT 8192, 스펙트럼 피크 + 포물선 보간, 골짜기 기준 돋보임 검사, 반음별 온셋, 배음 억제(2~24배음, 동시·최근·지속음 배음 그림자), 최저음역 옥타브 보정(약한 기음 대신 잡힌 2배음을 한 옥타브 아래로).
