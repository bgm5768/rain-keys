# Rain Keys · 빗방울 건반

**https://bgm5768.github.io/rain-keys/**

기기에서 나오는 소리(유튜브, 멜론, 직접 치는 피아노…)를 실시간으로 듣고, **음 높이 = 건반 위치, 박자 = 물에 닿는 순간**으로 빗방울을 떨어뜨리는 웹앱입니다. 소리를 재생하지 않고 분석만 합니다.

- 화면 위 88건반(A0~C8)이 실제 피아노 배치 그대로. 소리가 들린 건반 바로 아래로 비가 떨어지고, 낮은 음은 크고 무거운 방울, 높은 음은 작고 가벼운 방울이 됩니다.
- 실제 3D 세계에 카메라를 낮게 둔 실사 느낌: 바람 속 빗줄기, 실제 크기의 스플래시(크라운·물기둥·튀는 물방울), 수면 파문과 반사, 피사계 심도.
- 배경 4종, 실제 시각대로 뜨고 지는 해와 달, 천둥·번개, 바다 파도, 환경음.

## 쓰는 법

1. 사이트를 열고 화면을 한 번 누릅니다.
   - **PC(Chrome·Edge)**: 공유 창에서 '공유'만 누르면 기기 소리를 듣습니다(전체 화면·오디오가 미리 골라져 있음).
   - **휴대폰**: 마이크로 듣습니다.
2. 음악을 틀면 비가 내립니다. 오른쪽 아래 ⚙에서 설정을 바꿀 수 있어요.

| 설정 | 내용 |
|---|---|
| 배경 | 네온 호수 · 도시 · 등대 바다(파도가 세트로 와서 부서짐, 등대 불빛) · 오로라 호수(기본) |
| 시간대 | 실시간(기본, 지금 시각의 해·달·달 모양) · 새벽 · 아침 · 황혼 · 밤 |
| 비 효과 | 잔잔한 비(기본) · 물결 가득 |
| 곡 분위기 | 아주 조용 ~ 아주 시끄러움 5단계(조용할수록 여린 음까지 빗방울로) |
| 비 떨어지는 속도 | 100~500ms 5단계(물에 닿는 순간을 소리에 맞춤, 기본 빠르게 200ms) |
| 환경음 | 빗소리·물소리. 켜 두면 음악 없이도 비가 무작위로 내림(휴대폰은 처음부터 켜짐) |
| 천둥·번개 | 무작위로 치는 번개와 거리만큼 늦게 오는 천둥 |
| AI 음 인식 (테스트) | 스포티파이 Basic Pitch 모델로 음을 알아냄. 합성 피아노 시험에서 정확도 약 87% → 93~97% |
| 건반 표시 · 저사양 | 기본 꺼짐. 느려지면 저사양이 자동으로 켜짐 |

설정은 브라우저에 저장됩니다. 주소로도 지정할 수 있어요: `?bg=city&time=dusk&scene=lively&ai=1`.

## Windows 데스크톱 앱 · 화면보호기

`desktop/`의 Electron 앱은 공유 창이나 마이크 권한 없이 PC의 모든 소리를 바로 듣고, Windows 화면보호기로도 등록할 수 있습니다. → [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md#데스크톱-앱)
